# IMP-05.01 — Make executable license checks match the written policy

Status: proposed; not implemented by this review.
Priority: P1 — confirmed policy bypass.
Dependencies: None.

## Evidence and impact

`docs/governance/license-policy.md` rejects unknown licenses. `config/license-policy/policy.json` allows NOASSERTION; check_spdx_licenses only compares exact strings against the forbidden set and ignores the allow list. Offline probes accepted NOASSERTION and MIT AND BUSL-1.1, while rejecting BUSL-1.1 alone.

Read [the review README](README.md) first. Recheck these observations against the working tree before implementation.

## Proposed allowed paths

`config/license-policy/**`; `tests/supply-chain/policy/**`; `docs/security/scan-policy.md`; `docs/governance/license-policy.md`; dependency declarations only for a reviewed SPDX parser.

## Bounded implementation steps

Define machine policy for missing/unknown, accepted and review-required expressions. Parse SPDX expressions instead of splitting strings loosely: AND requires all obligations accepted; OR needs a documented selected acceptable alternative. Scope exceptions by artifact/package/version with expiry and owner. Keep copyleft review decisions separate from whether software is open source. Inventory active components against recorded policy without guessing upstream licenses.

## Acceptance and verification

Regression tests must cover missing licenses, NOASSERTION, forbidden standalone and nested compound expressions, reviewed OR selection, malformed expressions and expired/out-of-scope exceptions. Run `.venv/bin/python -m pytest tests/supply-chain/policy`. Add a real fixture scan only after these pass.

## Non-goals and stop conditions

Do not blanket-allow unknown licenses to green an existing SBOM, invent approvals, or replace an installed component automatically.

If a required API, fixture, version or permission is unavailable, report the exact blocker. Do not fabricate a successful result. Hand off changed files, verification mode/outcomes and remaining risks; commit/push only when requested.
