## Add a common operational section to future runbooks

For each service, document purpose, dependencies, authoritative configuration, persistent state, localhost address, credential source, apply command, read-only health check, live functional test, restart implications, recovery boundary and the issue that owns further work.

For each workflow, document its immutable inputs, outputs, identity, failure stages, retry/idempotency behavior, cleanup scope and evidence location.

A test command's expected output must distinguish **passed**, **skipped**, **blocked**, and **not run**. Do not say “all checks pass” when required live checks were skipped.
