# Great Expectations configuration

Issue `03.07.a` uses Great Expectations as the selected local data-quality route.

The expectation suite in this directory is intentionally small and file-based. It validates the curated housing-sale Parquet dataset generated by `03.06` and emits machine-readable JSON results through `src/ml_platform/data_quality`.

No data-quality server, cloud service, or raw restricted row logging is configured here.
