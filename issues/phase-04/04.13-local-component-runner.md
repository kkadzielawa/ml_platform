# 04.13 — Run pipeline components locally

## Outcome

Provide a local runner that executes the same component images/contracts over fixtures without the orchestrator.

## Allowed paths

- `src/ml_platform/local_runner/**`
- `tests/integration/local_runner/**`
- `docs/pipelines/local-development.md`

## Deliverables

- Provide a local runner that executes the same component images/contracts over fixtures without the orchestrator.
- Support ordered execution and captured artifacts, not a second pipeline DSL.

## Acceptance

- Local result matches remote fixture within declared tolerance.
- Runner propagates component failure and stops downstream work.

## Verify

```bash
make test-local-pipeline
```

## Non-goals

- Emulating Kubernetes scheduling or distributed execution.
