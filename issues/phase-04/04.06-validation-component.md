# 04.06 — Add the data-validation component

## Outcome

Run the selected data-quality suite against an immutable dataset reference and publish a machine-readable report.

## Allowed paths

- `components/validate/**`
- `tests/components/validate/**`

## Deliverables

- Run the selected data-quality suite against an immutable dataset reference and publish a machine-readable report.
- Return a distinct failure code for quality-gate failure.

## Acceptance

- Good and each seeded bad fixture produce expected status.
- Report contains aggregate evidence without restricted row data.

## Verify

```bash
make test-component-validate
```

## Non-goals

- Transforming or committing data.
