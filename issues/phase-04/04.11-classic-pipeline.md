# 04.11 — Assemble the end-to-end classic ML pipeline

## Outcome

Compose snapshot, validate, transform, train, evaluate, and register using the selected orchestrator.

## Allowed paths

- `pipelines/classic_ml/**`
- `tests/pipelines/classic_ml/**`

## Deliverables

- Compose snapshot, validate, transform, train, evaluate, and register using the selected orchestrator.
- Compile/package without executing at import time.

## Acceptance

- Dependency graph and parameters match the portable contracts.
- Good fixture registers; bad quality and model regressions do not.

## Verify

```bash
make compile-classic-pipeline && make test-classic-pipeline-spec
```

## Non-goals

- Scheduling or production data.
