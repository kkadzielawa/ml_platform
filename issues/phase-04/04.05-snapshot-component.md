# 04.05 — Add the dataset snapshot component

## Outcome

Resolve a mutable lakeFS branch or dataset reference to an immutable commit and emit its metadata artifact.

## Allowed paths

- `components/snapshot/**`
- `tests/components/snapshot/**`

## Deliverables

- Resolve a mutable lakeFS branch or dataset reference to an immutable commit and emit its metadata artifact.
- Do not copy dataset contents.

## Acceptance

- Valid reference emits the exact commit ID.
- Missing repository/branch fails with no output publication.

## Verify

```bash
make test-component-snapshot
```

## Non-goals

- Data validation or transformation.
