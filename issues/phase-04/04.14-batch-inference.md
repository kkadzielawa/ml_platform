# 04.14 — Add scheduled batch inference

## Outcome

Read an immutable registered model and dataset, produce versioned predictions, and schedule one disabled-by-default example.

## Allowed paths

- `components/batch_predict/**`
- `pipelines/batch_inference/**`
- `tests/pipelines/batch_inference/**`

## Deliverables

- Read an immutable registered model and dataset, produce versioned predictions, and schedule one disabled-by-default example.
- Include row IDs, model version, checksums, and manifest.

## Acceptance

- Repeated run is idempotent for the same run key.
- Schedule cannot accidentally target production prefixes.

## Verify

```bash
make test-batch-inference
```

## Non-goals

- Online serving.
