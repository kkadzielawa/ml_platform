# 04.04 — Create the reusable component SDK

## Outcome

Implement helpers for typed parameters, artifact download/upload, structured logs, run manifests, and lineage events.

## Allowed paths

- `src/ml_platform/components/**`
- `tests/unit/components/**`
- `build/component-base/**`
- `Makefile`

## Deliverables

- Implement helpers for typed parameters, artifact download/upload, structured logs, run manifests, and lineage events.
- Build a pinned non-root base image and a no-op example component.

## Acceptance

- No-op runs locally without external services using filesystem fixtures.
- Invalid contract input fails before side effects.

## Verify

```bash
make test-component-sdk && make build-component-base
```

## Non-goals

- Orchestrator-specific compilation.
