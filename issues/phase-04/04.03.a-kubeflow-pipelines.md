# 04.03.a — Install Kubeflow Pipelines standalone

## Outcome

Install a pinned standalone Kubeflow Pipelines backend and UI with constrained resources.

## Allowed paths

- `platform/charts/kfp/**`
- `clusters/dev/pipelines/**`
- `tests/integration/orchestrator/**`
- `docs/runbooks/pipelines.md`

## Deliverables

- Install a pinned standalone Kubeflow Pipelines backend and UI with constrained resources.
- Run a two-container artifact-passing smoke pipeline.

## Acceptance

- Pipeline succeeds without installing the full Kubeflow distribution.
- Artifact and parameters are visible through the API.

## Verify

```bash
make apply-orchestrator && make test-orchestrator
```

## Non-goals

- Authoring the production ML pipeline.
