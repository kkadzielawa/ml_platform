# 04.01 — Define the portable pipeline-component contract

## Outcome

Define container inputs, outputs, artifact URIs, exit codes, logging, run-manifest, and lineage behavior independent of an orchestrator.

## Allowed paths

- `contracts/pipeline-component.schema.json`
- `docs/pipelines/component-contract.md`
- `tests/contracts/pipelines/**`

## Deliverables

- Define container inputs, outputs, artifact URIs, exit codes, logging, run-manifest, and lineage behavior independent of an orchestrator.
- Add one valid and several invalid component specifications.

## Acceptance

- Contract covers cancellation, retry safety, and idempotency.
- No component requires shared in-memory state.

## Verify

```bash
make test-pipeline-contracts
```

## Non-goals

- Installing an orchestrator.
