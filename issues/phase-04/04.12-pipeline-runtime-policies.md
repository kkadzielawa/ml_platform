# 04.12 — Add caching, retry, timeout, and cleanup policies

## Outcome

Set explicit per-step cache keys, retry classes, timeouts, resource requests, and failure cleanup.

## Allowed paths

- `pipelines/classic_ml/**`
- `tests/pipelines/runtime_policies/**`
- `docs/pipelines/runtime-policy.md`

## Deliverables

- Set explicit per-step cache keys, retry classes, timeouts, resource requests, and failure cleanup.
- Add tests over rendered/compiled workflow definitions.

## Acceptance

- Training is not cached on an incomplete key.
- Non-idempotent registration has no blind retry.

## Verify

```bash
make test-pipeline-runtime-policies
```

## Non-goals

- Cluster-wide scheduler policies.
