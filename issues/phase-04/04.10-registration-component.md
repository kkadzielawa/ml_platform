# 04.10 — Add the gated MLflow registration component

## Outcome

Register and alias a candidate only when supplied a valid passing evaluation decision.

## Allowed paths

- `components/register_model/**`
- `tests/components/register_model/**`

## Deliverables

- Register and alias a candidate only when supplied a valid passing evaluation decision.
- Attach provenance, signature, license, and run-manifest references.

## Acceptance

- Passing decision registers exactly one version.
- Missing/tampered/failing decision registers nothing.

## Verify

```bash
make test-component-register-model
```

## Non-goals
