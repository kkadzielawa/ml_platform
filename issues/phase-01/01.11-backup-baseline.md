# 01.11 — Back up cluster metadata and state

## Outcome

Configure pinned Velero for namespace resources and document PostgreSQL/object-store native backup boundaries.

## Allowed paths

- `platform/charts/velero/**`
- `clusters/dev/backups/**`
- `scripts/backup/**`
- `docs/runbooks/backup.md`
- `tests/dr/**`

## Deliverables

- Configure pinned Velero for namespace resources and document PostgreSQL/object-store native backup boundaries.
- Create a labeled Phase-1 backup and inventory its contents.

## Acceptance

- Backup completes without including plaintext credentials in logs/artifacts.
- Runbook identifies what is and is not recoverable.

## Verify

```bash
make backup-phase-01 && make verify-backup-phase-01
```

## Non-goals

- Deleting live state or claiming an untested RPO.
