# 01.08 — Install CloudNativePG and a study database

## Outcome

Install the pinned operator and a single-instance non-HA study cluster with resource limits.

## Allowed paths

- `platform/charts/cloudnativepg/**`
- `clusters/dev/databases/**`
- `tests/integration/cloudnativepg/**`
- `docs/runbooks/postgres.md`

## Deliverables

- Install the pinned operator and a single-instance non-HA study cluster with resource limits.
- Add readiness, SQL, restart, and persistent-data smoke tests.

## Acceptance

- Data survives a database pod restart.
- Credentials are referenced through a Secret and not embedded in manifests.

## Verify

```bash
make apply-postgres && make test-cluster-postgres
```

## Non-goals

- HA, PITR, or application-specific databases.
