# 01.03 — Create Helm and Kustomize conventions

## Outcome

Define base/overlay layout, labels, namespace ownership, value-file rules, and render targets.

## Allowed paths

- `clusters/base/**`
- `clusters/dev/**`
- `platform/charts/**`
- `docs/platform/manifests.md`
- `tests/manifests/**`
- `Makefile`

## Deliverables

- Define base/overlay layout, labels, namespace ownership, value-file rules, and render targets.
- Add a test that renders every current manifest and rejects mutable image tags.

## Acceptance

- Rendered YAML parses successfully.
- No environment-specific value is placed in the base.

## Verify

```bash
make test-manifests
```

## Non-goals

- Installing applications.
