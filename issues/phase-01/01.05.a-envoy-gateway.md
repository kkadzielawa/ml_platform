# 01.05.a — Install Envoy Gateway

## Outcome

Install a pinned Envoy Gateway and one HTTPRoute echo fixture.

## Allowed paths

- `platform/charts/envoy-gateway/**`
- `clusters/dev/gateway/**`
- `tests/integration/gateway/**`
- `Makefile`

## Deliverables

- Install a pinned Envoy Gateway and one HTTPRoute echo fixture.
- Add a test that reaches the route through the mapped cluster port.

## Acceptance

- Gateway and route report accepted/programmed conditions.
- Unknown host/path does not reach the fixture.

## Verify

```bash
make apply-gateway && make test-gateway
```

## Non-goals

- TLS, authentication, or service-mesh features.
