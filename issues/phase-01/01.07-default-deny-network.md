# 01.07 — Apply default-deny network policy

## Outcome

Add default-deny ingress/egress for the example project plus explicit DNS and test-service allowances.

## Allowed paths

- `clusters/base/network-policies/**`
- `tests/integration/network/**`
- `Makefile`

- Add default-deny ingress/egress for the example project plus explicit DNS and test-service allowances.

make apply-network-policy && make test-network-policy
