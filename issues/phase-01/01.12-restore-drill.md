# 01.12 — Run a scoped Phase-1 restore drill

## Outcome

Restore the example namespace and test database into explicitly suffixed targets.

## Allowed paths

- `scripts/restore/**`
- `tests/dr/phase_01/**`
- `docs/runbooks/restore.md`
- `docs/reports/**`

## Deliverables

- Restore the example namespace and test database into explicitly suffixed targets.
- Record timing, recovered objects, checksums, and gaps.

## Acceptance

- Original resources are untouched.
- Restored SQL row and object checksum match the backup fixture.

## Verify

```bash
make restore-drill-phase-01
```

## Non-goals

- In-place overwrite or whole-cluster disaster recovery.
