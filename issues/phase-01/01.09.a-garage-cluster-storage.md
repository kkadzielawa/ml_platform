# 01.09.a — Deploy Garage object storage to the study cluster

## Outcome

Deploy pinned single-node Garage with a persistent volume and bootstrap Job.

## Allowed paths

- `platform/charts/garage/**`
- `clusters/dev/storage/**`
- `tests/integration/object_store/**`
- `docs/runbooks/object-storage.md`

## Deliverables

- Deploy pinned single-node Garage with a persistent volume and bootstrap Job.
- Reuse the S3 compatibility smoke-test contract from Phase 0.

## Acceptance

- Put/get/list/delete and checksum tests pass.
- Storage survives a pod restart.

## Verify

```bash
make apply-object-storage && make test-cluster-object-storage
```

## Non-goals

- Multi-node durability or Ceph.
