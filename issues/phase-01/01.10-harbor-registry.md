# 01.10 — Install the Harbor study registry

## Outcome

Install pinned Harbor with constrained resources and selected object storage where supported.

## Allowed paths

- `platform/charts/harbor/**`
- `clusters/dev/registry/**`
- `tests/integration/registry/**`
- `docs/runbooks/registry.md`

## Deliverables

- Install pinned Harbor with constrained resources and selected object storage where supported.
- Push, pull, and digest-verification smoke tests for one tiny image.

## Acceptance

- Pulled digest equals pushed digest.
- Anonymous push is rejected.

## Verify

```bash
make apply-registry && make test-registry
```

## Non-goals

- Replication, scanners, signing, or retention policies.
