# 01.09.c — Deploy Rook/Ceph to a suitable study cluster

## Outcome

Deploy pinned Rook/Ceph only on hosts satisfying the disk/memory preflight.

## Allowed paths

- `platform/charts/rook-ceph/**`
- `clusters/dev/storage/**`
- `tests/integration/object_store/**`
- `docs/runbooks/ceph.md`

## Deliverables

- Deploy pinned Rook/Ceph only on hosts satisfying the disk/memory preflight.
- Expose a study S3 bucket and a block StorageClass.

## Acceptance

- Preflight fails safely on insufficient or non-dedicated disks.
- S3 and persistent-volume smoke tests pass.

## Verify

```bash
make ceph-preflight && make apply-object-storage && make test-cluster-object-storage
```

## Non-goals

- Using the root disk, production tuning, or multi-site replication.
