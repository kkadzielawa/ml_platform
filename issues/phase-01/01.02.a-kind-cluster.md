# 01.02.a — Provision the study cluster with kind

## Outcome

Create a pinned kind cluster configuration with mapped ports and labeled worker nodes.

## Allowed paths

- `clusters/dev/kind/**`
- `scripts/cluster/**`
- `Makefile`
- `docs/runbooks/cluster.md`

## Deliverables

- Create a pinned kind cluster configuration with mapped ports and labeled worker nodes.
- Add create, status, and delete targets that refuse an unexpected cluster name.

## Acceptance

- Create and status pass on the recorded host.
- Delete targets only the exact study cluster.

## Verify

```bash
make cluster-create && make cluster-status
```

## Non-goals

- Persistent bare-metal storage or production HA.
