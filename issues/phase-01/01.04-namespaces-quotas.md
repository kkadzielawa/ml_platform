# 01.04 — Create platform and project namespaces

## Outcome

Create namespaces for platform services and one example project with ownership labels.

## Allowed paths

- `clusters/base/namespaces/**`
- `clusters/dev/quotas/**`
- `tests/manifests/**`

## Deliverables

- Create namespaces for platform services and one example project with ownership labels.
- Add ResourceQuota and LimitRange suitable for the recorded study host.

## Acceptance

- Pods without reasonable resources are rejected in the project namespace.
- Platform and project quotas do not overlap ownership.

## Verify

```bash
make test-manifests && make apply-namespaces
```

## Non-goals

- RBAC, network policy, or GPU quotas.
