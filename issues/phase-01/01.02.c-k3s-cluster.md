# 01.02.c — Provision the study cluster with K3s

## Outcome

Install a pinned single-node K3s study cluster through idempotent Ansible.

## Allowed paths

- `clusters/dev/k3s/**`
- `infra/ansible/k3s/**`
- `Makefile`
- `docs/runbooks/cluster.md`

## Deliverables

- Install a pinned single-node K3s study cluster through idempotent Ansible.
- Add status and uninstall documentation; uninstall requires explicit reviewer invocation.

## Acceptance

- Two Ansible runs produce no unintended changes.
- Cluster node becomes Ready and uses the recorded container runtime.

## Verify

```bash
make cluster-provision && make cluster-status
```

## Non-goals

- Running uninstall automatically or configuring multi-node HA.
