# 01.06 — Add local TLS certificate management

## Outcome

Install pinned cert-manager and create a study-only local issuer.

## Allowed paths

- `platform/charts/cert-manager/**`
- `clusters/dev/tls/**`
- `tests/integration/tls/**`
- `docs/runbooks/local-ca.md`

## Deliverables

- Install pinned cert-manager and create a study-only local issuer.
- Issue a certificate for the echo route and document local trust setup.

## Acceptance

- Certificate becomes Ready and HTTPS smoke test passes with the configured CA.
- Plain HTTP behavior matches the recorded redirect/reject policy.

## Verify

```bash
make apply-tls && make test-tls
```

## Non-goals

- Public ACME issuance or production PKI.
