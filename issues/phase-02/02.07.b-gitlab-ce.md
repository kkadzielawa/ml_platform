# 02.07.b — Deploy GitLab CE CI

## Outcome

Deploy a pinned GitLab CE configuration sized for the study cluster with one runner.

## Allowed paths

- `platform/charts/gitlab/**`
- `clusters/dev/ci/**`
- `tests/integration/ci/**`
- `docs/runbooks/ci.md`

## Deliverables

- Deploy a pinned GitLab CE configuration sized for the study cluster with one runner.
- Run a sample project pipeline that tests and builds a tiny image.

## Acceptance

- Pipeline trigger is attributable to a commit.
- Runner identity can push only to the intended registry project.

## Verify

```bash
make apply-ci && make test-ci
```

## Non-goals

- Enterprise features, production HA, or repository migration.
