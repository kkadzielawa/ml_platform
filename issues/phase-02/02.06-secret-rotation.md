# 02.06 — Demonstrate credential rotation

## Outcome

Rotate the OIDC fixture's test credential through the selected secret route.

## Allowed paths

- `tests/integration/secrets/rotation/**`
- `scripts/security/**`
- `docs/runbooks/secret-rotation.md`

## Deliverables

- Rotate the OIDC fixture's test credential through the selected secret route.
- Verify the application adopts the new value and the old value fails.

## Acceptance

- Rotation does not require editing plaintext in Git.
- Logs do not reveal either credential.

## Verify

```bash
make test-secret-rotation
```

## Non-goals

- Rotating all platform credentials.
