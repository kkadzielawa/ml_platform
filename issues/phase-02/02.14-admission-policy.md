# 02.14 — Reject unsigned or noncompliant images

## Outcome

Install pinned Kyverno and enforce signature verification in the example project namespace.

## Allowed paths

- `platform/charts/kyverno/**`
- `platform/policies/supply-chain/**`
- `tests/integration/admission/**`

## Deliverables

- Install pinned Kyverno and enforce signature verification in the example project namespace.
- Add allow, unsigned-deny, and policy-exception-expiry tests.

## Acceptance

- Unsigned image is rejected with an actionable message.
- Platform-system namespaces follow the explicitly documented rollout mode.

## Verify

```bash
make apply-admission-policy && make test-admission-policy
```

## Non-goals

- Cluster-wide enforcement without a staged rollout.
