# 02.05.a — Deploy OpenBao with External Secrets

## Outcome

Deploy pinned OpenBao in study mode with persistent storage and External Secrets Operator.

## Allowed paths

- `platform/charts/openbao/**`
- `platform/charts/external-secrets/**`
- `clusters/dev/secrets/**`
- `tests/integration/secrets/**`
- `docs/runbooks/secrets.md`

## Deliverables

- Deploy pinned OpenBao in study mode with persistent storage and External Secrets Operator.
- Sync one scoped database credential into the example namespace.

## Acceptance

- Secret value is absent from Git and rendered manifests.
- Unauthorized service account cannot read the external secret.

## Verify

```bash
make apply-secrets && make test-secrets
```

## Non-goals

- Production unseal architecture, HSMs, or broad secret migration.
