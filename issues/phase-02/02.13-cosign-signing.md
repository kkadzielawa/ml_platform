# 02.13 — Sign and verify the fixture image

## Outcome

Sign the accepted fixture digest with pinned Cosign using a study key or documented keyless flow.

## Allowed paths

- `config/cosign/**`
- `scripts/supply-chain/**`
- `tests/supply-chain/signing/**`
- `docs/runbooks/signing.md`

## Deliverables

- Sign the accepted fixture digest with pinned Cosign using a study key or documented keyless flow.
- Verify signature and SBOM attestation.

## Acceptance

- Tampered digest fails verification.
- Private key material is not committed.

## Verify

```bash
make sign-fixture && make verify-fixture
```

## Non-goals

- Production key management or admission enforcement.
