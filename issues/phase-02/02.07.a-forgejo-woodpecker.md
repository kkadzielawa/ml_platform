# 02.07.a — Deploy Forgejo and Woodpecker CI

## Outcome

Deploy pinned Forgejo and Woodpecker and connect them with a scoped service identity.

## Allowed paths

- `platform/charts/forgejo/**`
- `platform/charts/woodpecker/**`
- `clusters/dev/ci/**`
- `tests/integration/ci/**`
- `docs/runbooks/ci.md`

## Deliverables

- Deploy pinned Forgejo and Woodpecker and connect them with a scoped service identity.
- Run a sample repository pipeline that tests and builds a tiny image.

## Acceptance

- Pipeline trigger is attributable to a commit.
- CI identity can push only to the intended registry project.

## Verify

```bash
make apply-ci && make test-ci
```

## Non-goals

- Migrating the current repository or production runner isolation.
