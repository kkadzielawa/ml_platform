# 02.03 — Protect one test application with OIDC

## Outcome

Register a confidential client and protect the echo fixture with an OIDC-capable proxy or native middleware.

## Allowed paths

- `examples/oidc_echo/**`
- `clusters/dev/identity/clients/**`
- `tests/integration/oidc/**`

## Deliverables

- Register a confidential client and protect the echo fixture with an OIDC-capable proxy or native middleware.
- Test unauthenticated, viewer, and admin paths.

## Acceptance

- Unauthenticated access is redirected/rejected.
- Role claim controls the admin path.

## Verify

```bash
make apply-oidc-fixture && make test-oidc
```

## Non-goals

- Kubernetes API authentication or application-specific authorization.
