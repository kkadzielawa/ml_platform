# 02.10 — Build reproducible OCI images

## Outcome

Create a BuildKit-based build for the fixture app using pinned bases and a minimal runtime user.

## Allowed paths

- `build/**`
- `examples/build_fixture/**`
- `tests/supply-chain/**`
- `Makefile`

## Deliverables

- Create a BuildKit-based build for the fixture app using pinned bases and a minimal runtime user.
- Build twice and document any digest differences.

## Acceptance

- Image runs as non-root and exposes no build-time secret.
- Base image is pinned by digest.

## Verify

```bash
make build-fixture && make test-image
```

## Non-goals

- SBOM, vulnerability scan, or signing.
