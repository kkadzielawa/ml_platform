# 02.02 — Install Keycloak with a study realm

## Outcome

Deploy pinned Keycloak backed by its own PostgreSQL database.

## Allowed paths

- `platform/charts/keycloak/**`
- `clusters/dev/identity/**`
- `tests/integration/keycloak/**`
- `docs/runbooks/keycloak.md`

## Deliverables

- Deploy pinned Keycloak backed by its own PostgreSQL database.
- Import a declarative study realm with admin, learner, viewer, and service roles.

## Acceptance

- Realm import is repeatable.
- Default/bootstrap credentials are rotated or supplied externally.

## Verify

```bash
make apply-keycloak && make test-keycloak
```

## Non-goals

- Connecting every application or production SSO federation.
