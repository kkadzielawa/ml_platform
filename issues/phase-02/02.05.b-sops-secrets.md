# 02.05.b — Configure SOPS and age for the study cluster

## Outcome

Configure pinned SOPS/age and GitOps-compatible decryption for one example secret.

## Allowed paths

- `config/sops/**`
- `.sops.yaml`
- `clusters/dev/secrets/**`
- `tests/integration/secrets/**`
- `docs/runbooks/secrets.md`

## Deliverables

- Configure pinned SOPS/age and GitOps-compatible decryption for one example secret.
- Document key custody and recovery for a single learner.

## Acceptance

- Only ciphertext is committed.
- Deployment can decrypt in the intended controller context and not from an unconfigured context.

## Verify

```bash
make test-encrypted-secrets
```

## Non-goals

- Dynamic credentials, server-side secret leasing, or production key custody.
