# 02.11 — Generate software bills of materials

## Outcome

Generate SPDX and/or CycloneDX SBOMs for the fixture image with pinned Syft.

## Allowed paths

- `config/syft/**`
- `tests/supply-chain/sbom/**`
- `Makefile`

## Deliverables

- Generate SPDX and/or CycloneDX SBOMs for the fixture image with pinned Syft.
- Attach or publish the SBOM alongside the image digest.

## Acceptance

- SBOM contains application and OS packages.
- Test fails if the SBOM references a different image digest.

## Verify

```bash
make sbom-fixture && make test-sbom
```

## Non-goals

- Legal conclusions or vulnerability scanning.
