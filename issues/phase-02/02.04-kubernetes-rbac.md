# 02.04 — Map identity groups to Kubernetes RBAC

## Outcome

Create project-viewer, project-editor, and platform-observer roles and bindings using OIDC group names.

## Allowed paths

- `clusters/base/rbac/**`
- `tests/integration/rbac/**`
- `docs/security/kubernetes-access.md`

## Deliverables

- Create project-viewer, project-editor, and platform-observer roles and bindings using OIDC group names.
- Add `kubectl auth can-i` tests for permitted and forbidden actions.

## Acceptance

- Viewer cannot mutate resources or read Secrets.
- Editor cannot access another project namespace.

## Verify

```bash
make apply-rbac && make test-rbac
```

## Non-goals

- Granting cluster-admin or configuring workstation login plugins.
