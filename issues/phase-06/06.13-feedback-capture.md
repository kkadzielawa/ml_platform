# 06.13 — Capture explicit user feedback

## Outcome

Add authenticated feedback endpoint keyed to prediction/request ID with schema, idempotency, and abuse limits.

## Allowed paths

- `services/inference_gateway/feedback/**`
- `contracts/openapi/prediction.yaml`
- `tests/services/inference_gateway/feedback/**`

## Deliverables

- Add authenticated feedback endpoint keyed to prediction/request ID with schema, idempotency, and abuse limits.
- Store feedback separately from telemetry payloads.

## Acceptance

- Duplicate idempotency key does not double count.
- Caller cannot submit feedback for an inaccessible request.

## Verify

```bash
make test-feedback-api
```

## Non-goals

- Treating feedback as ground truth.
