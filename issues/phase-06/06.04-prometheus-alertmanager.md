# 06.04 — Deploy metrics and alert routing

## Outcome

Deploy pinned Prometheus and Alertmanager, replacing or migrating the Phase-0 lab instances.

## Allowed paths

- `platform/charts/prometheus/**`
- `platform/charts/alertmanager/**`
- `clusters/dev/observability/metrics/**`
- `tests/integration/metrics/**`

## Deliverables

- Deploy pinned Prometheus and Alertmanager, replacing or migrating the Phase-0 lab instances.
- Route test alerts to a local sink.

## Acceptance

- Targets are healthy and one synthetic alert reaches the sink.
- Alerts include owner/runbook labels.

## Verify

```bash
make apply-metrics && make test-metrics-alerts
```

## Non-goals

- External paging integration.
