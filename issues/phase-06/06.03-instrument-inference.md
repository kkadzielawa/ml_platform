# 06.03 — Instrument inference services

## Outcome

Add OpenTelemetry spans/metrics/log correlation around validation, model call, and response without double instrumentation.

## Allowed paths

- `services/inference_gateway/**`
- `src/ml_platform/telemetry/**`
- `tests/services/inference_gateway/telemetry/**`

## Deliverables

- Add OpenTelemetry spans/metrics/log correlation around validation, model call, and response without double instrumentation.
- Propagate request/run/model/deployment IDs.

## Acceptance

- One request yields a connected trace with expected spans.
- Cancellation/error sets status without recording payload contents.

## Verify

```bash
make test-inference-telemetry
```

## Non-goals

- RAG/LLM semantic conventions.
