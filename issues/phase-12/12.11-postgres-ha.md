# 12.11 — Exercise PostgreSQL HA and recovery

## Outcome

Create a disposable CloudNativePG HA simulation with replicas, backup/PITR configuration, and forced primary failure.

## Allowed paths

- `clusters/prod/databases/**`
- `tests/resilience/postgres/**`
- `docs/runbooks/postgres-ha.md`

## Deliverables

- Create a disposable CloudNativePG HA simulation with replicas, backup/PITR configuration, and forced primary failure.
- Use fixture databases only.

## Acceptance

- Client reconnects/fails according to documented behavior.
- Restore reaches recorded target and checksums match.

## Verify

```bash
make test-postgres-ha
```

## Non-goals

- Changing the development database in place.
