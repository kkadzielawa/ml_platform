# 12.04 — Provision per-project compute and queue quotas

## Outcome

Render/apply CPU, memory, storage, pod, and optional accelerator/Kueue limits from project config.

## Allowed paths

- `platform/projects/modules/quotas/**`
- `tests/integration/project_quotas/**`

## Deliverables

- Render/apply CPU, memory, storage, pod, and optional accelerator/Kueue limits from project config.
- Add over-quota and fair-sharing tests.

## Acceptance

- Project cannot exceed limits.
- Platform system workloads are not charged to the project quota.

## Verify

```bash
make test-project-quotas
```

## Non-goals

- Financial billing.
