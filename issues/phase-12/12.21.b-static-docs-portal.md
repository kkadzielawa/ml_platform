# 12.21.b — Build a MkDocs-based study portal

## Outcome

Build a versioned MkDocs site linking templates, APIs, cards, dashboards, runbooks, and ownership.

## Allowed paths

- `docs-site/**`
- `mkdocs.yml`
- `tests/docs/**`
- `docs/user-guide/portal.md`

## Deliverables

- Build a versioned MkDocs site linking templates, APIs, cards, dashboards, runbooks, and ownership.
- Generate API reference from OpenAPI without embedding credentials.

## Acceptance

- Link and build checks pass.
- State-changing actions remain CLI/API operations.

## Verify

```bash
make build-docs && make test-docs
```

## Non-goals

- Dynamic service catalog or self-service UI.
