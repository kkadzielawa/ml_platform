# 12.05 — Provision per-project network isolation

## Outcome

Generate default-deny and explicit DNS/platform-service ingress/egress policies per project.

## Allowed paths

- `platform/projects/modules/network/**`
- `tests/security/project_network/**`

## Deliverables

- Generate default-deny and explicit DNS/platform-service ingress/egress policies per project.
- Test two generated projects.

## Acceptance

- Cross-project traffic fails by default.
- Required platform endpoints remain reachable only on documented ports.

## Verify

```bash
make test-project-network-isolation
```

## Non-goals

- Service mesh.
