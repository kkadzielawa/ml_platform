# 12.22 — Define support, ownership, and deprecation policy

## Outcome

Define owners, support levels, release/version policy, dependency update cadence, compatibility window, migration notice, and removal evidence.

## Allowed paths

- `docs/operations/support.md`
- `docs/operations/deprecation.md`
- `contracts/deprecation.schema.json`

## Deliverables

- Define owners, support levels, release/version policy, dependency update cadence, compatibility window, migration notice, and removal evidence.
- Apply policy to one deprecated fixture version.

## Acceptance

- Every golden template/component has an owner/support level.
- Removal cannot occur before recorded migration/notice criteria.

## Verify

```bash
make test-deprecation-policy
```

## Non-goals

- Providing an on-call organization.
