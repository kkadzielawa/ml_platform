# 12.03 — Automate namespace and baseline resource onboarding

## Outcome

Idempotently create project namespaces, labels, service accounts, and baseline configs from the manifest.

## Allowed paths

- `services/platform_api/projects/**`
- `scripts/projects/**`
- `tests/integration/project_onboarding/**`

## Deliverables

- Idempotently create project namespaces, labels, service accounts, and baseline configs from the manifest.
- Record ownership and status.

## Acceptance

- Second apply is a no-op.
- Partial failure can resume or roll back created fixture resources.

## Verify

```bash
make test-project-onboarding
```

## Non-goals

- Identity, storage, or quota provisioning.
