# 12.15 — Run a platform disaster-recovery simulation

## Outcome

Restore selected GitOps state, PostgreSQL, object data, registry/model/vector metadata into a fresh/suffixed environment.

## Allowed paths

- `tests/dr/platform/**`
- `scripts/dr/**`
- `docs/runbooks/disaster-recovery.md`
- `docs/reports/dr.md`

## Deliverables

- Restore selected GitOps state, PostgreSQL, object data, registry/model/vector metadata into a fresh/suffixed environment.
- Validate a classic prediction and RAG query from restored assets.

## Acceptance

- Measured recovery and data loss are reported against study RPO/RTO.
- Original environment remains untouched.

## Verify

```bash
make test-platform-dr
```

## Non-goals

- Real-site failover.
