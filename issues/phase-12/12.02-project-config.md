# 12.02 — Create declarative project configuration

## Outcome

Create a validated project manifest format and renderer for names, labels, roles, quotas, and service entitlements.

## Allowed paths

- `platform/projects/**`
- `tests/platform/projects/**`
- `docs/platform/project-config.md`

## Deliverables

- Create a validated project manifest format and renderer for names, labels, roles, quotas, and service entitlements.
- Use a generated example project.

## Acceptance

- Invalid/colliding project IDs fail before rendering.
- Renderer is deterministic.

## Verify

```bash
make test-project-config
```

## Non-goals

- Applying resources.
