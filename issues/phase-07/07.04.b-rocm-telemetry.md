# 07.04.b — Deploy AMD GPU telemetry

## Outcome

Deploy the pinned supported AMD/ROCm metrics exporter and a minimal health/utilization dashboard.

## Allowed paths

- `platform/charts/amd-gpu-exporter/**`
- `clusters/dev/observability/gpu/**`
- `tests/integration/gpu_metrics/**`
- `platform/dashboards/gpu/**`

## Deliverables

- Deploy the pinned supported AMD/ROCm metrics exporter and a minimal health/utilization dashboard.
- Normalize labels needed for workload correlation.

## Acceptance

- A controlled GPU workload changes utilization/memory metrics.
- Unsupported device metrics are documented, not fabricated.

## Verify

```bash
make apply-gpu-metrics && make test-gpu-metrics
```

## Non-goals

- DCGM or vendor-independent parity.
