# 07.08.b — Create a distributed DeepSpeed runtime

## Outcome

Create a pinned Kubeflow Trainer MPI/DeepSpeed runtime for the detected accelerator stack.

## Allowed paths

- `runtimes/training/deepspeed/**`
- `tests/integration/training_runtime/**`
- `docs/training/deepspeed-runtime.md`

## Deliverables

- Create a pinned Kubeflow Trainer MPI/DeepSpeed runtime for the detected accelerator stack.
- Include resources, topology metadata, rendezvous, and non-root image settings.

## Acceptance

- Two processes complete a ZeRO smoke training step and synchronize parameters.
- Runtime records ranks, devices, config, and versions.

## Verify

```bash
make apply-training-runtime && make test-training-runtime
```

## Non-goals

- Large-model training or PyTorch-runtime comparison.
