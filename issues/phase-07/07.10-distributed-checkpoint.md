# 07.10 — Add checkpoint and resume

## Outcome

Write atomic run-scoped checkpoints to object storage with model/optimizer/scheduler/RNG/topology metadata.

## Allowed paths

- `examples/distributed_training/**`
- `src/ml_platform/checkpointing/**`
- `tests/integration/checkpointing/**`
- `docs/training/checkpoints.md`

## Deliverables

- Write atomic run-scoped checkpoints to object storage with model/optimizer/scheduler/RNG/topology metadata.
- Resume from an explicit checkpoint after interruption.

## Acceptance

- Resumed final metrics match uninterrupted tolerance.
- Incomplete checkpoint is ignored/rejected.

## Verify

```bash
make test-distributed-checkpoint
```

## Non-goals

- Elastic world-size changes unless explicitly supported.
