# 07.08.a — Create a distributed PyTorch runtime

## Outcome

Create a pinned Kubeflow Trainer runtime using torchrun and the detected collective backend.

## Allowed paths

- `runtimes/training/pytorch/**`
- `tests/integration/training_runtime/**`
- `docs/training/pytorch-runtime.md`

## Deliverables

- Create a pinned Kubeflow Trainer runtime using torchrun and the detected collective backend.
- Include resources, topology metadata, rendezvous, and non-root image settings.

## Acceptance

- Two processes complete all-reduce correctness test.
- Runtime records world size, ranks, devices, and versions.

## Verify

```bash
make apply-training-runtime && make test-training-runtime
```

## Non-goals

- DeepSpeed or model training.
