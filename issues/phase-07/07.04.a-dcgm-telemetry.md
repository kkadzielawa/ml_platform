# 07.04.a — Deploy NVIDIA DCGM Exporter

## Outcome

Deploy pinned DCGM Exporter and provision a minimal GPU health/utilization dashboard.

## Allowed paths

- `platform/charts/dcgm-exporter/**`
- `clusters/dev/observability/gpu/**`
- `tests/integration/gpu_metrics/**`
- `platform/dashboards/gpu/**`

## Deliverables

- Deploy pinned DCGM Exporter and provision a minimal GPU health/utilization dashboard.
- Correlate pod/namespace/node labels without GPU UUID cardinality mistakes.

## Acceptance

- A controlled GPU workload changes utilization/memory metrics.
- No metric exposes credentials or user data.

## Verify

```bash
make apply-gpu-metrics && make test-gpu-metrics
```

## Non-goals

- Energy attribution accuracy or alert tuning.
