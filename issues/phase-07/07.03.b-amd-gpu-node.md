# 07.03.b — Enable an AMD ROCm GPU node

## Outcome

Install the pinned ROCm stack and Kubernetes device plugin for the recorded hardware.

## Allowed paths

- `clusters/dev/gpu/amd/**`
- `infra/ansible/gpu/amd/**`
- `tests/hardware/gpu_node/**`
- `docs/runbooks/gpu-node.md`

## Deliverables

- Install the pinned ROCm stack and Kubernetes device plugin for the recorded hardware.
- Label/taint the GPU node and run a ROCm allocation smoke pod.

## Acceptance

- Exactly requested GPUs are visible inside the pod.
- CPU workloads do not land on the tainted node without toleration.

## Verify

```bash
make gpu-preflight && make apply-gpu-node && make test-gpu-allocation
```

## Non-goals

- NVIDIA CUDA compatibility, driver upgrades, or fabric tuning.
