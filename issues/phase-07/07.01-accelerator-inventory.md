# 07.01 — Inventory accelerator hardware and constraints

## Outcome

Collect model, memory, driver, runtime, topology, interconnect, power limits, and allocatable device facts without changing the host.

## Allowed paths

- `docs/hardware/accelerators.md`
- `scripts/hardware/inventory/**`
- `tests/hardware/**`

## Deliverables

- Collect model, memory, driver, runtime, topology, interconnect, power limits, and allocatable device facts without changing the host.
- Record CPU-only fallback for tests.

## Acceptance

- Inventory output contains no host secrets.
- Reviewer confirms hardware spending/use authorization.

## Verify

```bash
make accelerator-inventory && make test-accelerator-inventory
```

## Non-goals

- Installing drivers or changing host configuration.
