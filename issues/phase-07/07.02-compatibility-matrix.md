# 07.02 — Pin the accelerator compatibility matrix

## Outcome

Pin Kubernetes, driver, device plugin/operator, container runtime, PyTorch, collective library, and training image versions for the detected vendor.

## Allowed paths

- `config/accelerator-versions.yaml`
- `docs/hardware/compatibility.md`
- `tests/config/accelerators/**`

## Deliverables

- Pin Kubernetes, driver, device plugin/operator, container runtime, PyTorch, collective library, and training image versions for the detected vendor.
- Link each compatibility claim to primary documentation.

## Acceptance

- No floating versions are present.
- A preflight test rejects incompatible detected versions.

## Verify

```bash
make test-accelerator-versions
```

## Non-goals

- Installing the stack.
