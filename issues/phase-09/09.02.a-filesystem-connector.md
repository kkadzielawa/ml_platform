# 09.02.a — Build a local-filesystem source connector

## Outcome

Ingest a fixed allowlisted directory containing a small redistributable document corpus.

## Allowed paths

- `connectors/filesystem/**`
- `tests/connectors/filesystem/**`
- `examples/rag_baseline/corpus/**`

## Deliverables

- Ingest a fixed allowlisted directory containing a small redistributable document corpus.
- Emit source records with checksums and deletion markers without following unsafe links.

## Acceptance

- New/change/delete cases are deterministic.
- Path traversal and symlink escape are rejected.

## Verify

```bash
make test-rag-connector
```

## Non-goals

- Network sources or scheduling.
