# 09.02.b — Build an allowlisted HTTP source connector

## Outcome

Fetch a fixed local HTTP fixture with allowlisted host, content/size/time limits, ETag/checksum, and deletion handling.

## Allowed paths

- `connectors/http/**`
- `tests/connectors/http/**`
- `examples/rag_baseline/corpus/**`

## Deliverables

- Fetch a fixed local HTTP fixture with allowlisted host, content/size/time limits, ETag/checksum, and deletion handling.
- Do not crawl arbitrary links.

## Acceptance

- Changed/unchanged/missing responses map correctly.
- Private/link-local/redirect-to-disallowed targets are rejected.

## Verify

```bash
make test-rag-connector
```

## Non-goals

- General web crawling.
