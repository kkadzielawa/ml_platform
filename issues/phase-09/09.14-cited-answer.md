# 09.14 — Generate answers with resolvable citations

## Outcome

Build a typed RAG endpoint that retrieves, reranks, constructs bounded context, calls the LLM, and returns source citations.

## Allowed paths

- `services/rag_api/**`
- `contracts/openapi/rag.yaml`
- `tests/services/rag_api/**`

## Deliverables

- Build a typed RAG endpoint that retrieves, reranks, constructs bounded context, calls the LLM, and returns source citations.
- Resolve citations only from supplied chunks.

## Acceptance

- Every returned citation maps to source/version/location allowed to caller.
- Prompt requests cannot forge unprovided source IDs.

## Verify

```bash
make test-rag-api
```

## Non-goals

- Conversational memory or agents.
