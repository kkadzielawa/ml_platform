# 09.05 — Detect and redact configured PII before indexing

## Outcome

Pin Presidio or implement deterministic detectors for the fixture's configured PII types.

## Allowed paths

- `components/redact_documents/**`
- `config/presidio/**`
- `tests/components/redact_documents/**`
- `docs/rag/redaction.md`

## Deliverables

- Pin Presidio or implement deterministic detectors for the fixture's configured PII types.
- Store redacted text for indexing and a restricted audit summary, not raw matches in logs.

## Acceptance

- Seeded PII is absent from chunks/telemetry.
- False-positive fixture and allowlist behavior are tested.

## Verify

```bash
make test-rag-redaction
```

## Non-goals

- Guaranteeing complete de-identification.
