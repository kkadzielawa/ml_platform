# 09.16 — Create separate retrieval and answer evaluation gates

## Outcome

Compute retrieval recall/MRR/nDCG, citation validity, deterministic answer checks, groundedness/relevance judge labels, abstention, latency, and token usage.

## Allowed paths

- `components/evaluate_rag/**`
- `examples/rag_baseline/eval/**`
- `tests/components/evaluate_rag/**`
- `docs/reports/**`

## Deliverables

- Compute retrieval recall/MRR/nDCG, citation validity, deterministic answer checks, groundedness/relevance judge labels, abstention, latency, and token usage.
- Version judge prompts/models and retain samples for human review.

## Acceptance

- Seeded retrieval and hallucination regressions fail distinct gates.
- Judge metrics are labeled as estimates, not ground truth.

## Verify

```bash
make evaluate-rag && make test-rag-evaluation
```

## Non-goals

- Online production evaluation.
