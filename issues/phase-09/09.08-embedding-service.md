# 09.08 — Deploy a pinned embedding model

## Outcome

Select, license-record, pin, and serve a small embedding model locally with batching and input limits.

## Allowed paths

- `config/embeddings.yaml`
- `runtimes/serving/embeddings/**`
- `tests/integration/embedding_service/**`
- `docs/rag/embeddings.md`

## Deliverables

- Select, license-record, pin, and serve a small embedding model locally with batching and input limits.
- Record tokenizer/model revision and output normalization.

## Acceptance

- Known text yields stable dimension and approximate repeatability.
- Oversized input and unknown model are rejected.

## Verify

```bash
make deploy-embedding-service && make test-embedding-service
```

## Non-goals

- Reranking or cloud embeddings.
