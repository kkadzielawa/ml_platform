# 09.11 — Implement and evaluate dense retrieval

## Outcome

Embed queries, perform filtered top-k search, and return typed scored chunks/citations.

## Allowed paths

- `src/ml_platform/rag/retrieval/**`
- `tests/rag/retrieval/**`
- `examples/rag_baseline/eval/**`

## Deliverables

- Embed queries, perform filtered top-k search, and return typed scored chunks/citations.
- Create a small golden query-to-relevant-chunk set.

## Acceptance

- Recall@k is computed and meets recorded baseline.
- Denied relevant chunk is excluded.

## Verify

```bash
make test-dense-retrieval
```

## Non-goals

- Hybrid retrieval or generation.
