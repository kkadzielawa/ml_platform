# 09.09 — Build the versioned indexing component

## Outcome

Embed chunks and transactionally write a new immutable logical index version with source/chunker/embedder metadata.

## Allowed paths

- `components/index_rag/**`
- `tests/components/index_rag/**`
- `pipelines/rag_index/**`

## Deliverables

- Embed chunks and transactionally write a new immutable logical index version with source/chunker/embedder metadata.
- Publish only after completeness checks.

## Acceptance

- Forced mid-run failure leaves no active partial index.
- Rebuild is idempotent for identical version inputs.

## Verify

```bash
make test-rag-indexer
```

## Non-goals

- Incremental CDC or index aliases.
