# 08.11 — Register adapter/base compatibility

## Outcome

Register the adapter as a distinct MLflow/model asset linked to exact base, tokenizer, data, config, and evaluation state.

## Allowed paths

- `src/ml_platform/model_registry/adapters/**`
- `tests/integration/adapter_registry/**`
- `contracts/model-asset.schema.json`

## Deliverables

- Register the adapter as a distinct MLflow/model asset linked to exact base, tokenizer, data, config, and evaluation state.
- Prevent alias promotion before evaluation.

## Acceptance

- Incompatible base revision is rejected.
- Artifact hash and license/provenance are searchable.

## Verify

```bash
make test-adapter-registry
```

## Non-goals

- Deploying the adapter.
