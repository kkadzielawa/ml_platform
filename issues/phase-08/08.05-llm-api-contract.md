# 08.05 — Define and expose the LLM gateway contract

## Outcome

Add model-list and chat/completion endpoints with typed messages, generation parameters, usage, errors, and model-version metadata.

## Allowed paths

- `contracts/openapi/llm.yaml`
- `services/inference_gateway/llm/**`
- `tests/services/inference_gateway/llm/**`

## Deliverables

- Add model-list and chat/completion endpoints with typed messages, generation parameters, usage, errors, and model-version metadata.
- Authorize only catalog aliases and map them to immutable deployments.

## Acceptance

- Unknown model/parameter is rejected.
- Internal runtime endpoint remains private.

## Verify

```bash
make test-llm-gateway
```

## Non-goals

- Streaming, tool calls, or embeddings.
