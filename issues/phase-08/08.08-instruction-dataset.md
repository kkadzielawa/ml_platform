# 08.08 — Create a versioned instruction-tuning fixture

## Outcome

Create a tiny licensed/generated instruction dataset with train/eval split, conversation template, provenance, and contamination checks.

## Allowed paths

- `examples/llm_finetune/data/**`
- `contracts/instruction-data.schema.json`
- `tests/data/llm_instruction/**`

## Deliverables

- Create a tiny licensed/generated instruction dataset with train/eval split, conversation template, provenance, and contamination checks.
- Commit it through the versioned data path.

## Acceptance

- No eval example is duplicated in train.
- Schema rejects missing roles/provenance.

## Verify

```bash
make test-instruction-data
```

## Non-goals

- Large scraped datasets or preference data.
