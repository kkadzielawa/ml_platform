# 08.03 — Import and verify model weights

## Outcome

Download only cataloged files, verify hashes/license metadata, scan formats, and copy to immutable object/MLflow artifacts.

## Allowed paths

- `scripts/models/import/**`
- `src/ml_platform/model_assets/**`
- `tests/integration/model_import/**`
- `docs/runbooks/model-import.md`

## Deliverables

- Download only cataloged files, verify hashes/license metadata, scan formats, and copy to immutable object/MLflow artifacts.
- Produce the model-asset manifest.

## Acceptance

- Hash mismatch or unapproved remote code fails before publication.
- Rerun is idempotent.

## Verify

```bash
make import-study-model && make test-model-import
```

## Non-goals

- Serving or modifying weights.
