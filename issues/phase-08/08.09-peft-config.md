# 08.09 — Define a resource-bounded PEFT experiment

## Outcome

Pin LoRA/QLoRA targets, rank, precision, sequence length, batching, optimizer, seed, checkpoints, and maximum runtime.

## Allowed paths

- `pipelines/llm_finetune/configs/**`
- `docs/experiments/peft-baseline.md`
- `tests/config/peft/**`

## Deliverables

- Pin LoRA/QLoRA targets, rank, precision, sequence length, batching, optimizer, seed, checkpoints, and maximum runtime.
- Estimate memory and define abort threshold.

## Acceptance

- Config validates against model architecture.
- Resource estimate fits authorized hardware.

