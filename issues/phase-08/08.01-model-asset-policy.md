# 08.01 — Define model-weight and adapter policy

## Outcome

Define allowed weight licenses, provenance, hashes, model cards, use restrictions, remote-code policy, and adapter/base compatibility.

## Allowed paths

- `docs/governance/model-policy.md`
- `contracts/model-asset.schema.json`
- `tests/contracts/models/**`

## Deliverables

- Define allowed weight licenses, provenance, hashes, model cards, use restrictions, remote-code policy, and adapter/base compatibility.
- Add accepted, review-required, and rejected fixtures.

## Acceptance

- Unrecorded license or required remote code fails policy.
- Adapter record references exact base revision.

## Verify

```bash
make test-model-asset-policy
```

## Non-goals

- Selecting or downloading a model.
