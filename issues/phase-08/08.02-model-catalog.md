# 08.02 — Create the approved study model catalog

## Outcome

Select one small openly licensed text model and tokenizer that fit available hardware, plus optional CPU fallback.

## Allowed paths

- `config/models.yaml`
- `docs/models/catalog.md`
- `tests/config/models/**`

## Deliverables

- Select one small openly licensed text model and tokenizer that fit available hardware, plus optional CPU fallback.
- Pin repository revisions, file hashes, context limit, and intended uses.

## Acceptance

- Catalog has no floating revision.
- Estimated memory fits the declared study profile.

## Verify

```bash
make test-model-catalog
```

## Non-goals

- Downloading weights.
