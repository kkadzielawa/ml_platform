# 08.12 — Evaluate base and adapter on held-out tasks

## Outcome

Run deterministic/task metrics and structured human-review samples for base and adapter on fixed held-out data.

## Allowed paths

- `components/evaluate_llm/**`
- `examples/llm_finetune/eval/**`
- `tests/components/evaluate_llm/**`
- `docs/reports/**`

## Deliverables

- Run deterministic/task metrics and structured human-review samples for base and adapter on fixed held-out data.
- Report improvements, regressions, uncertainty, latency, and token usage.

## Acceptance

- Evaluator uses the same generation settings for both.
- No train example appears in the held-out set.

## Verify

```bash
make evaluate-base-adapter && make test-llm-evaluator
```

## Non-goals

- Safety evaluation or deployment.
