# 08.14.a — Create an AWQ quantized candidate

## Outcome

Pin a compatible AWQ toolchain, quantize immutable weights, and emit a new model-asset manifest.

## Allowed paths

- `components/quantize_llm/**`
- `config/quantization/awq/**`
- `tests/components/quantize_llm/**`
- `docs/experiments/quantization.md`

## Deliverables

- Pin a compatible AWQ toolchain, quantize immutable weights, and emit a new model-asset manifest.
- Run a small correctness/perplexity/task comparison.

## Acceptance

- Quantized artifact is separate and hash-addressed.
- Quality loss and memory change are measured.

## Verify

```bash
make quantize-study-model && make test-quantized-model
```

## Non-goals

- Overwriting base weights or universal performance claims.
