# 08.04.a — Serve the study model with vLLM

## Outcome

Package/deploy pinned vLLM against immutable local weights with an OpenAI-compatible internal endpoint.

## Allowed paths

- `runtimes/serving/vllm/**`
- `clusters/dev/serving/llm/**`
- `tests/integration/llm_runtime/**`
- `docs/serving/vllm.md`

## Deliverables

- Package/deploy pinned vLLM against immutable local weights with an OpenAI-compatible internal endpoint.
- Set explicit precision, context, memory, and concurrency limits.

## Acceptance

- Known deterministic request returns expected schema.
- Endpoint cannot fetch arbitrary remote models.

## Verify

```bash
make deploy-llm-runtime && make test-llm-runtime
```

## Non-goals

- Gateway, quotas, or distributed serving.
