# 05.08 — Add asynchronous batch prediction submission

## Outcome

Submit a batch job by immutable input URI/model version and return status/result references.

## Allowed paths

- `services/inference_gateway/batch/**`
- `tests/services/inference_gateway/batch/**`
- `contracts/openapi/prediction.yaml`

## Deliverables

- Submit a batch job by immutable input URI/model version and return status/result references.
- Reuse the Phase-4 batch component rather than processing large batches in the HTTP request.

## Acceptance

- Duplicate idempotency key returns the same job.
- Caller cannot write results outside its allowed project prefix.

## Verify

```bash
make test-batch-api
```

## Non-goals

- A general workflow API.
