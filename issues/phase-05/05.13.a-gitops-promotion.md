# 05.13.a — Promote models through GitOps

## Outcome

Create a reviewed manifest change that pins model/image/evaluation references and advances canary weight.

## Allowed paths

- `clusters/dev/serving/releases/**`
- `scripts/serving/promote/**`
- `tests/integration/promotion/**`
- `docs/serving/promotion.md`

## Deliverables

- Create a reviewed manifest change that pins model/image/evaluation references and advances canary weight.
- Add validation that refuses a missing/failing evaluation ID.

## Acceptance

- Every deployment maps to a commit and immutable digests.
- Rollback is a revert/new promotion commit.

## Verify

```bash
make test-model-promotion
```

## Non-goals

- Writing a custom controller.
