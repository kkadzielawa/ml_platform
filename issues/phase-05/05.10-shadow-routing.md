# 05.10 — Mirror traffic to a shadow model safely

## Outcome

Mirror eligible requests asynchronously to a shadow version without affecting primary responses.

## Allowed paths

- `services/inference_gateway/shadow/**`
- `clusters/dev/serving/routing/shadow/**`
- `tests/integration/shadow/**`

## Deliverables

- Mirror eligible requests asynchronously to a shadow version without affecting primary responses.
- Redact or exclude requests according to data class.

## Acceptance

- Shadow failure does not change primary status/latency beyond threshold.
- Shadow outputs are not returned to callers.

## Verify

```bash
make test-shadow-routing
```

## Non-goals

- Production PII policy or model comparison UI.
