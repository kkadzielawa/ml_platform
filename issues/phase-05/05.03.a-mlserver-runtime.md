# 05.03.a — Package the baseline with MLServer

## Outcome

Package pinned MLServer to load an explicit MLflow sklearn model from object storage.

## Allowed paths

- `runtimes/serving/mlserver/**`
- `tests/integration/model_runtime/**`
- `build/runtimes/**`

- Package pinned MLServer to load an explicit MLflow sklearn model from object storage.
- Map runtime protocol to the common prediction contract.

## Acceptance

- Known fixture prediction matches Phase 0.
- Unknown model version and malformed input fail safely.

## Verify

```bash
make build-model-runtime && make test-model-runtime
```
