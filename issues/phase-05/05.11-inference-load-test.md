# 05.11 — Create a repeatable load test

## Outcome

Create a k6/Locust workload with fixed dataset, request mix, warmup, concurrency, and duration.

## Allowed paths

- `tests/performance/inference/**`
- `docs/benchmarks/inference-baseline.md`
- `Makefile`

## Deliverables

- Create a k6/Locust workload with fixed dataset, request mix, warmup, concurrency, and duration.
- Capture correctness, throughput, errors, p50/p95/p99 latency, CPU, and memory.

## Acceptance

- Test fails on correctness or declared error threshold.
- Report records hardware/software versions and workload shape.

## Verify

```bash
make benchmark-inference
```

## Non-goals

- Claiming universal performance.
