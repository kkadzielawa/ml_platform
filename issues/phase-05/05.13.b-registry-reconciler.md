# 05.13.b — Build a minimal registry-to-deployment reconciler

## Outcome

Watch an explicit approved MLflow alias/event and create a proposed immutable deployment record.

## Allowed paths

- `services/model_reconciler/**`
- `tests/services/model_reconciler/**`
- `clusters/dev/model_reconciler/**`
- `docs/serving/promotion.md`

## Deliverables

- Watch an explicit approved MLflow alias/event and create a proposed immutable deployment record.
- Require a passing evaluation and use idempotent reconciliation.

## Acceptance

- Duplicate events do not create duplicate deployments.
- Missing approval/evaluation causes no mutation.

## Verify

```bash
make test-model-reconciler
```

## Non-goals

- Automatic production rollout without review.
