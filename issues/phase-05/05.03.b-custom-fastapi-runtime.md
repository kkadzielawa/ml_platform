# 05.03.b — Package the baseline with a custom FastAPI runtime

## Outcome

Package the Phase-0 typed service as a non-root model runtime using explicit MLflow model version.

## Allowed paths

- `runtimes/serving/fastapi/**`
- `tests/integration/model_runtime/**`
- `build/runtimes/**`

## Deliverables

- Package the Phase-0 typed service as a non-root model runtime using explicit MLflow model version.
- Expose the selected controller's required health and inference protocol adapters.

## Acceptance

- Known prediction matches Phase 0.
- Image contains no registry/object-store credentials.

## Verify

```bash
make build-model-runtime && make test-model-runtime
```

## Non-goals

- General multi-framework serving.
