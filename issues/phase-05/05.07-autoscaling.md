# 05.07 — Configure measured autoscaling

## Outcome

Configure min/max replicas and one supported autoscaling signal for the model/facade.

## Allowed paths

- `clusters/dev/serving/autoscaling/**`
- `tests/integration/autoscaling/**`
- `docs/serving/autoscaling.md`

## Deliverables

- Configure min/max replicas and one supported autoscaling signal for the model/facade.
- Use a bounded load fixture to demonstrate scale-up and scale-down.

## Acceptance

- Replica count stays within declared bounds.
- Scale behavior is documented if scale-to-zero is unsupported.

## Verify

```bash
make test-inference-autoscaling
```

## Non-goals

- Production capacity guarantees.
