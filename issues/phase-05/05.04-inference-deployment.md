# 05.04 — Deploy the registered baseline model

## Outcome

Deploy an immutable baseline model version through the selected controller/runtime.

## Allowed paths

- `clusters/dev/serving/models/**`
- `tests/integration/inference_deployment/**`
- `docs/serving/deployment.md`

## Deliverables

- Deploy an immutable baseline model version through the selected controller/runtime.
- Record image digest, model URI/version, resources, and route.

## Acceptance

- Endpoint becomes Ready and predicts correctly.
- Changing the registry alias alone does not mutate the deployed version.

## Verify

```bash
make deploy-baseline-model && make test-deployed-model
```

## Non-goals

- Application facade, autoscaling, or canaries.
