# 05.14 — Automate safe model rollback

## Outcome

Rollback from candidate to last-known-good immutable version using the selected promotion route.

## Allowed paths

- `scripts/serving/rollback/**`
- `tests/integration/rollback/**`
- `docs/runbooks/model-rollback.md`

## Deliverables

- Rollback from candidate to last-known-good immutable version using the selected promotion route.
- Test rollback during a failing canary.

## Acceptance

- Known-good endpoint passes before rollback is declared complete.
- Audit record links trigger, actor, old/new versions, and timing.

## Verify

```bash
make test-model-rollback
```

## Non-goals

- Deleting the failed model or artifacts.
