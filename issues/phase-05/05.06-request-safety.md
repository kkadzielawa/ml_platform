# 05.06 — Add timeouts, limits, and safe errors

## Outcome

Configure connect/total timeouts, payload/batch limits, concurrency guard, cancellation propagation, and sanitized errors.

## Allowed paths

- `services/inference_gateway/**`
- `tests/services/inference_gateway/safety/**`
- `docs/serving/request-policy.md`

## Deliverables

- Configure connect/total timeouts, payload/batch limits, concurrency guard, cancellation propagation, and sanitized errors.
- Add slow-upstream and malformed-payload tests.

## Acceptance

- Timed-out request releases local resources.
- Response/logs contain no stack trace or input payload by default.

## Verify

```bash
make test-inference-request-safety
```

## Non-goals

- Autoscaling or external rate limiting.
