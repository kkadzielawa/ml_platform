# 05.01 — Define the online prediction contract

## Outcome

Define health, readiness, metadata, predict, errors, request ID, model version, and batch limits in OpenAPI.

## Allowed paths

- `contracts/openapi/prediction.yaml`
- `contracts/examples/prediction/**`
- `tests/contracts/prediction/**`

## Deliverables

- Define health, readiness, metadata, predict, errors, request ID, model version, and batch limits in OpenAPI.
- Add valid and invalid request/response fixtures.

## Acceptance

- Contract covers single and batch prediction plus validation errors.
- No framework-specific model object leaks through the API.

## Verify

```bash
make test-prediction-contract
```

## Non-goals

- Deploying a serving controller.
