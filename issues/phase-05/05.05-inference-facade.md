# 05.05 — Add the FastAPI inference facade

## Outcome

Implement the OpenAPI contract, OIDC authorization, typed validation, and forwarding to the internal model endpoint.

## Allowed paths

- `services/inference_gateway/**`
- `tests/services/inference_gateway/**`
- `clusters/dev/inference_gateway/**`

## Deliverables

- Implement the OpenAPI contract, OIDC authorization, typed validation, and forwarding to the internal model endpoint.
- Keep model runtime inaccessible through the public Gateway.

## Acceptance

- Public valid request succeeds with request/model IDs.
- Unauthenticated, invalid, and oversized requests fail as specified.

## Verify

```bash
make test-inference-gateway && make deploy-inference-gateway
```

## Non-goals

- Retries, rate limits, or batch jobs.
