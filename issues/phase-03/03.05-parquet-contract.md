# 03.05 — Define Parquet dataset conventions

## Outcome

Define schema metadata, partition naming, timestamps/timezones, nullability, categorical encoding, and small-file guidance.

## Allowed paths

- `contracts/dataset.schema.json`
- `docs/data/parquet.md`
- `tests/contracts/datasets/**`

## Deliverables

- Define schema metadata, partition naming, timestamps/timezones, nullability, categorical encoding, and small-file guidance.
- Add valid and invalid metadata fixtures.

## Acceptance

- Schema evolution compatibility cases are tested.
- Contract does not require loading an entire dataset into memory.

## Verify

```bash
make test-dataset-contracts
```

## Non-goals

- Iceberg transaction semantics.
