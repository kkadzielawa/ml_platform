# 03.04 — Deploy lakeFS over the selected object store

## Outcome

Deploy pinned lakeFS with PostgreSQL metadata and scoped object access.

## Allowed paths

- `platform/charts/lakefs/**`
- `clusters/dev/lakefs/**`
- `tests/integration/lakefs/**`
- `docs/runbooks/lakefs.md`

## Deliverables

- Deploy pinned lakeFS with PostgreSQL metadata and scoped object access.
- Test repository create, branch, commit, merge, tag, and read by commit.

## Acceptance

- Two commits preserve distinct object contents.
- Credentials are not embedded in repository configuration.

## Verify

```bash
make apply-lakefs && make test-lakefs
```

## Non-goals

- Production GC, HA, or large-data performance.
