# 03.08 — Build a versioned ingestion command

## Outcome

Ingest the baseline source into a temporary lakeFS branch, validate it, write curated Parquet, and commit only on success.

## Allowed paths

- `src/ml_platform/ingestion/**`
- `tests/integration/ingestion/**`
- `scripts/data/**`
- `Makefile`

## Deliverables

- Ingest the baseline source into a temporary lakeFS branch, validate it, write curated Parquet, and commit only on success.
- Emit the universal run manifest with source and lakeFS commit IDs.

## Acceptance

- Bad input leaves the target branch uncommitted.
- Successful rerun is idempotent or creates a clearly linked no-op run.

## Verify

```bash
make ingest-baseline && make test-ingestion
```

## Non-goals

- Scheduling or catalog publication.
