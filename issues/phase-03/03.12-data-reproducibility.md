# 03.12 — Reproduce an old curated dataset

## Outcome

Create two source versions, build curated outputs, then reproduce the first output by immutable reference.

## Allowed paths

- `tests/e2e/phase_03/**`
- `scripts/phase_03/**`
- `docs/reports/data-reproducibility.md`

## Deliverables

- Create two source versions, build curated outputs, then reproduce the first output by immutable reference.
- Compare schema, row count, and content checksum.

## Acceptance

- Reproduced output matches the first version and differs from the second where expected.
- Report links lineage and run manifests.

## Verify

```bash
make e2e-data-reproducibility
```

## Non-goals

- Performance benchmarking.
