# 03.01 — Define data classes and object layout

## Outcome

Define public/internal/confidential/restricted classes, retention expectations, and bucket/prefix ownership.

## Allowed paths

- `docs/data/classification.md`
- `docs/data/object-layout.md`
- `contracts/data-asset.schema.json`

## Deliverables

- Define public/internal/confidential/restricted classes, retention expectations, and bucket/prefix ownership.
- Define dataset IDs, versions, checksums, schemas, and license/provenance metadata.

## Acceptance

- Every Phase-0 artifact maps to a class and prefix.
- Restricted examples prohibit logging raw values.

## Verify

```bash
make test-contracts
```

## Non-goals

- Creating buckets or migrating Phase-0 data.
