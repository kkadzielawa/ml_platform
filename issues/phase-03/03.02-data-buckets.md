# 03.02 — Provision scoped data buckets

## Outcome

Create raw, curated, artifacts, models, and evaluation buckets/prefixes with separate scoped credentials.

## Allowed paths

- `clusters/dev/data-storage/**`
- `scripts/data/bootstrap/**`
- `tests/integration/data_storage/**`

## Deliverables

- Create raw, curated, artifacts, models, and evaluation buckets/prefixes with separate scoped credentials.
- Add positive and cross-scope negative tests.

## Acceptance

- Each identity accesses only documented prefixes.
- Bucket creation is idempotent.

## Verify

```bash
make apply-data-storage && make test-data-storage-access
```

## Non-goals

- Lifecycle rules or lakeFS.
