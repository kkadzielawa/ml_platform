# 11.01 — Define one bounded agent use case and threat model

## Outcome

Specify user, task, state, allowed tools, data, side effects, trust boundaries, budgets, approvals, and success/failure measures.

## Allowed paths

- `docs/agents/use-case.md`
- `docs/security/agent-threat-model.md`
- `adr/**`

## Deliverables

- Specify user, task, state, allowed tools, data, side effects, trust boundaries, budgets, approvals, and success/failure measures.
- Choose a read-mostly study task before any code execution.

## Acceptance

- At least prompt injection, tool poisoning, confused deputy, exfiltration, runaway loop, and replay are addressed.
- Reviewer approves each side effect and credential scope.

## Verify

```bash
rg -n 'Tools|Budgets|Approval|prompt injection|exfiltration' docs/security/agent-threat-model.md
```

## Non-goals
