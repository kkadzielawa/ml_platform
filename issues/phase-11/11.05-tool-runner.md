# 11.05 — Execute allowlisted tools with validation

## Outcome

Validate arguments, authorize tool/version, enforce timeout/output size, execute fixture, validate result, and wrap errors as untrusted events.

## Allowed paths

- `services/agent_runtime/tools/runner/**`
- `tests/services/agent_runtime/tools/runner/**`

## Deliverables

- Validate arguments, authorize tool/version, enforce timeout/output size, execute fixture, validate result, and wrap errors as untrusted events.
- Never execute a model-provided command string.

## Acceptance

- Malformed input/output and unknown tool fail closed.
- Timeout terminates fixture and records status.

## Verify

```bash
make test-agent-tool-runner
```

## Non-goals

- Shell/browser/code execution.
