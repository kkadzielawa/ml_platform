# 11.09 — Implement end-to-end cancellation

## Outcome

Accept authenticated cancellation, stop future steps, propagate to model/tool activities, and checkpoint terminal status.

## Allowed paths

- `services/agent_runtime/cancellation/**`
- `tests/services/agent_runtime/cancellation/**`

## Deliverables

- Accept authenticated cancellation, stop future steps, propagate to model/tool activities, and checkpoint terminal status.
- Handle cancellation races with completion.

## Acceptance

- Cancelled run performs no later side effect.
- Repeated cancellation is idempotent.

## Verify

```bash
make test-agent-cancellation
```

## Non-goals

- Compensating already completed effects.
