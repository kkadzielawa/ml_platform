# 11.04 — Create the typed tool registry

## Outcome

Register tool name/version, JSON input/output schemas, side-effect class, auth scope, timeout, idempotency, and owner.

## Allowed paths

- `services/agent_runtime/tools/registry/**`
- `contracts/agent/tool.schema.json`
- `tests/services/agent_runtime/tools/registry/**`

## Deliverables

- Register tool name/version, JSON input/output schemas, side-effect class, auth scope, timeout, idempotency, and owner.
- Add one pure calculator/read-only fixture.

## Acceptance

- Unknown/version-mismatched tool is rejected.
- Registry cannot store credential values.

## Verify

```bash
make test-agent-tool-registry
```

## Non-goals

- Executing external tools.
