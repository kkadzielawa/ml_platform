# 11.02 — Define typed agent state and event contracts

## Outcome

Define request, messages, plan/step, tool call/result, approval, checkpoint, error, budget, and terminal output schemas.

## Allowed paths

- `contracts/agent/state.schema.json`
- `contracts/agent/event.schema.json`
- `tests/contracts/agent/**`
- `docs/agents/state.md`

## Deliverables

- Define request, messages, plan/step, tool call/result, approval, checkpoint, error, budget, and terminal output schemas.
- Version events and distinguish trusted control data from untrusted content.

## Acceptance

- Invalid transitions/payloads are represented as failures.
- Secrets and raw credentials have no schema field.

## Verify

```bash
make test-agent-contracts
```

## Non-goals

- Choosing an orchestration framework.
