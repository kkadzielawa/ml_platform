# 11.15 — Build the agent evaluation harness

## Outcome

Evaluate task success, tool selection/arguments, trajectory length, policy violations, approvals, latency, tokens, and retries on fixed tasks.

## Allowed paths

- `components/evaluate_agent/**`
- `examples/bounded_agent/eval/**`
- `tests/components/evaluate_agent/**`
- `docs/reports/**`

## Deliverables

- Evaluate task success, tool selection/arguments, trajectory length, policy violations, approvals, latency, tokens, and retries on fixed tasks.
- Separate deterministic checks, human labels, and judge estimates.

## Acceptance

- Seeded wrong-tool and excessive-step agents fail distinct metrics.
- Evaluation captures exact model/tool/prompt/policy versions.

## Verify

```bash
make evaluate-agent && make test-agent-evaluation
```

## Non-goals

- Online production evaluation.
