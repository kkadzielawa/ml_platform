# 11.06 — Issue scoped tool credentials

## Outcome

Resolve short-lived/scoped credentials from identity and tool policy at execution time without adding them to state.

## Allowed paths

- `services/agent_runtime/credentials/**`
- `clusters/dev/agent_runtime/**`
- `tests/security/agent_credentials/**`
- `docs/agents/credentials.md`

## Deliverables

- Resolve short-lived/scoped credentials from identity and tool policy at execution time without adding them to state.
- Use a fake protected read-only service.

## Acceptance

- Credential is inaccessible to model prompt/state/output/logs.
- Wrong agent/tool/project scope is rejected.

## Verify

```bash
make test-agent-credentials
```

## Non-goals

- Privileged production integrations.
