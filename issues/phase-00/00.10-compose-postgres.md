# 00.10 — Add local PostgreSQL

## Outcome

Add pinned PostgreSQL with a health check, named volume, non-default local credentials via environment variables, and an initialization script.

## Allowed paths

- `compose.yaml`
- `config/postgres/**`
- `tests/integration/postgres/**`
- `Makefile`
- `.env.example`

## Deliverables

- Add pinned PostgreSQL with a health check, named volume, non-default local credentials via environment variables, and an initialization script.
- Add a smoke test that creates, reads, and removes a test table.

## Acceptance

- No real secret is committed.
- Service becomes healthy and the smoke test passes from a clean volume.

## Verify

```bash
make compose-up-postgres && make test-postgres
```

## Non-goals

- High availability, backups, pgvector, or application databases beyond the smoke test.
