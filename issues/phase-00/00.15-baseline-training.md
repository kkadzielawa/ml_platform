# 00.15 — Train and register the baseline model

## Outcome

Train one sklearn baseline, log parameters/metrics/artifacts to MLflow, emit a valid run manifest, and register only above the recorded threshold.

## Allowed paths

- `examples/sklearn_baseline/train.py`
- `examples/sklearn_baseline/config.yaml`
- `examples/sklearn_baseline/tests/**`
- `src/ml_platform/run_manifest/**`
- `Makefile`

## Deliverables

- Train one sklearn baseline, log parameters/metrics/artifacts to MLflow, emit a valid run manifest, and register only above the recorded threshold.
- Add deterministic unit and integration tests.

## Acceptance

- A fixed-seed run meets the documented threshold.
- A deliberately failing metric does not register a model.

## Verify

```bash
make train-baseline && make test-baseline-training
```

## Non-goals

- Hyperparameter search, deployment, or multiple algorithms.
