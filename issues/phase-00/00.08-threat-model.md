# 00.08 — Write the local-lab threat model

## Outcome

List assets, trust boundaries, actors, entry points, threats, and mitigations for local services.

## Allowed paths

- `docs/security/threat-model.md`

## Deliverables

- List assets, trust boundaries, actors, entry points, threats, and mitigations for local services.
- Include model files, datasets, prompts, credentials, notebooks, and agent/tool output.

## Acceptance

- At least one misuse case covers data exfiltration and one covers malicious model/artifact loading.
- Residual risks and out-of-scope production threats are explicit.

## Verify

```bash
test -f docs/security/threat-model.md && rg -n 'Trust boundaries|Residual risk|exfiltration' docs/security/threat-model.md
```

## Non-goals

- Implementing mitigations or claiming production security.
