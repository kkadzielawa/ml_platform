# 00.09 — Create the open-source and asset license policy

## Outcome

Define accepted software licenses, review-required copyleft licenses, and rejected source-available defaults.

## Allowed paths

- `docs/governance/license-policy.md`
- `contracts/license-record.schema.json`
- `tests/contracts/**`

## Deliverables

- Define accepted software licenses, review-required copyleft licenses, and rejected source-available defaults.
- Define separate records for software, model weights, datasets, and generated adapters.

## Acceptance

- The policy distinguishes OSI open source from source available.
- Schema examples cover a package, model, and dataset.

## Verify

```bash
make test-contracts
```

## Non-goals

- Performing legal review or scanning the full dependency tree.
