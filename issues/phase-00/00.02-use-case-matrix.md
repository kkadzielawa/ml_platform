# 00.02 — Record initial use cases and success measures

## Outcome

Define one classic-ML and one RAG use case using a common template.

## Allowed paths

- `docs/use-cases.md`

## Deliverables

- Define one classic-ML and one RAG use case using a common template.
- Specify dataset, user, output, offline metric, service metric, safety constraint, and baseline.

## Acceptance

- Both rows contain numeric success thresholds.
- Unknown values are marked as open decisions, not invented.

## Verify

```bash
test -f docs/use-cases.md && rg -n 'Classic ML|RAG|Baseline|Threshold' docs/use-cases.md
```

## Non-goals

- Implementing either use case.
