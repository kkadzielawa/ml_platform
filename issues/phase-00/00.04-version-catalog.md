# 00.04 — Pin the initial tool and image versions

## Outcome

Create a schema-validated catalog of Python, base image, PostgreSQL, MLflow, and observability versions used in Phase 0.

## Allowed paths

- `config/versions.yaml`
- `docs/version-policy.md`
- `tests/config/**`
- `Makefile`

## Deliverables

- Create a schema-validated catalog of Python, base image, PostgreSQL, MLflow, and observability versions used in Phase 0.
- Document how versions are researched, pinned by digest where possible, and updated.

## Acceptance

- No catalog value is `latest` or an unbounded range.
- A test rejects missing and floating versions.

## Verify

```bash
make test-versions
```

## Non-goals

- Installing or upgrading the pinned software.
