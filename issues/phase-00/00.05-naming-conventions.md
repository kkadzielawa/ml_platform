# 00.05 — Define names, labels, and artifact prefixes

## Outcome

Define project/run/model/dataset/environment naming rules and required labels.

## Allowed paths

- `docs/conventions.md`
- `contracts/naming.schema.json`
- `tests/contracts/**`

## Deliverables

- Define project/run/model/dataset/environment naming rules and required labels.
- Define object prefixes without embedding credentials or personal data.

## Acceptance

- Valid and invalid examples are tested against the schema.
- Names are portable across filesystems, DNS labels, and object storage where required.

## Verify

```bash
make test-contracts
```

## Non-goals

- Creating buckets, databases, or Kubernetes resources.
