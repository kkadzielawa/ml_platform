# 00.16 — Serve the registered baseline locally

## Outcome

Add a typed FastAPI prediction endpoint that loads an explicit MLflow model version.

## Allowed paths

- `examples/sklearn_baseline/service/**`
- `examples/sklearn_baseline/tests/test_service.py`
- `compose.yaml`
- `Makefile`

## Deliverables

- Add a typed FastAPI prediction endpoint that loads an explicit MLflow model version.
- Add health, metadata, valid prediction, and invalid-payload tests.

## Acceptance

- Response includes model version and request ID.
- Invalid schema returns a 4xx response without a stack trace.

## Verify

```bash
make serve-baseline-smoke
```

## Non-goals

- Autoscaling, KServe, authentication, or canary routing.
