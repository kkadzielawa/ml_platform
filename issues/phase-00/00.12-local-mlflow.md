# 00.12 — Add local MLflow tracking and registry

## Outcome

Run pinned MLflow with PostgreSQL metadata and the selected S3 artifact store.

## Allowed paths

- `compose.yaml`
- `config/mlflow/**`
- `tests/integration/mlflow/**`
- `Makefile`

## Deliverables

- Run pinned MLflow with PostgreSQL metadata and the selected S3 artifact store.
- Add a smoke test that creates an experiment, logs a metric and artifact, and reads them back.

## Acceptance

- MLflow does not use local filesystem artifact persistence.
- The smoke test is repeatable and cleans its test run.

## Verify

```bash
make compose-up-mlflow && make test-mlflow
```

## Non-goals

- Training a real model or configuring production authentication.
