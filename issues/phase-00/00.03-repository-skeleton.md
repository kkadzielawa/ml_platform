# 00.03 — Create the repository skeleton

## Outcome

Create the directories defined in the implementation plan with placeholder README files only where needed.

## Allowed paths

- `adr/**`
- `docs/**`
- `contracts/**`
- `config/**`
- `src/**`
- `tests/**`
- `examples/**`
- `Makefile`
- `pyproject.toml`
- `.gitignore`

## Deliverables

- Create the directories defined in the implementation plan with placeholder README files only where needed.
- Add a minimal Python package, pytest smoke test, and `make test` target.

## Acceptance

- A clean environment can install the package.
- `make test` passes without external services.

## Verify

```bash
make test
```

## Non-goals

- Adding platform services or application logic.
