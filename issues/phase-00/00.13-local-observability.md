# 00.13 — Add local metrics dashboards

## Outcome

Add pinned Prometheus and Grafana with provisioned data source and one service-health dashboard.

## Allowed paths

- `compose.yaml`
- `config/prometheus/**`
- `config/grafana/**`
- `tests/integration/observability/**`
- `Makefile`

## Deliverables

- Add pinned Prometheus and Grafana with provisioned data source and one service-health dashboard.
- Add a smoke test for Prometheus readiness and a known metric query.

## Acceptance

- Dashboard and data source are provisioned from files.
- No manual UI configuration is required after a clean start.

## Verify

```bash
make compose-up-observability && make test-observability
```

## Non-goals

- Logs, traces, alert delivery, or model drift.
