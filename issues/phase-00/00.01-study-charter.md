# 00.01 — Define the study charter

## Outcome

Create `docs/charter.md` with learning goals, available hardware/budget, first three experiments, and explicit non-goals.

## Allowed paths

- `adr/**`
- `docs/charter.md`

## Deliverables

- Create `docs/charter.md` with learning goals, available hardware/budget, first three experiments, and explicit non-goals.
- Create an approved ADR recording that this is a study-first platform.

## Acceptance

- The charter contains measurable outcomes and resource limits.
- A reviewer approval checkbox is present and checked.

## Verify

```bash
test -f docs/charter.md && rg -n 'Goals|Hardware|Budget|Non-goals' docs/charter.md
```

## Non-goals

- Selecting infrastructure or installing software.
