# 00.07 — Define the universal run manifest

## Outcome

Implement the JSON Schema fields specified in section 6.1 of the plan.

## Allowed paths

- `contracts/run-manifest.schema.json`
- `contracts/examples/**`
- `tests/contracts/**`

## Deliverables

- Implement the JSON Schema fields specified in section 6.1 of the plan.
- Add one valid classic-ML example and invalid fixtures for missing provenance.

## Acceptance

- Schema accepts the valid example and rejects every invalid fixture.
- Artifact URIs, checksums, code revision, data revision, parameters, metrics, and license fields are represented.

## Verify

```bash
make test-contracts
```

## Non-goals

- Writing MLflow integration or collecting live hardware metadata.
