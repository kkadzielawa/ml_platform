# 00.14 — Create the baseline tabular dataset fixture

## Outcome

Add a small redistributable or generated classification dataset with deterministic train/test split metadata.

## Allowed paths

- `examples/sklearn_baseline/data/**`
- `examples/sklearn_baseline/README.md`
- `tests/examples/**`

## Deliverables

- Add a small redistributable or generated classification dataset with deterministic train/test split metadata.
- Document license/provenance, schema, target, and expected baseline.

## Acceptance

- Dataset generation is deterministic from a seed.
- Tests detect target leakage and schema changes.

## Verify

```bash
make test-baseline-data
```

## Non-goals

- Feature-store integration or large external downloads.
