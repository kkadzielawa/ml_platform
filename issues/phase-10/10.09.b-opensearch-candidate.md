# 10.09.b — Deploy OpenSearch as a search candidate

## Outcome

Deploy pinned OpenSearch with constrained resources and implement the common search adapter.

## Allowed paths

- `platform/charts/opensearch/**`
- `clusters/dev/vector_candidate/**`
- `adapters/vector_store/opensearch/**`
- `tests/integration/vector_candidate/**`

## Deliverables

- Deploy pinned OpenSearch with constrained resources and implement the common search adapter.
- Load the small workload and run dense, lexical, hybrid, and ACL-filter smoke tests.

## Acceptance

- Adapter returns contract-compatible scored IDs.
- Security plugin and resource costs are documented.

## Verify

```bash
make apply-vector-candidate && make test-vector-candidate
```

## Non-goals

- Migrating active data.
