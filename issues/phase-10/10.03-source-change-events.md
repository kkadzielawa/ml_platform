# 10.03 — Define normalized source change events

## Outcome

Define create/update/delete/move events with source version, event time, idempotency key, and sequence/cursor.

## Allowed paths

- `contracts/rag/source-change.schema.json`
- `connectors/common/**`
- `tests/contracts/rag/source_change/**`

## Deliverables

- Define create/update/delete/move events with source version, event time, idempotency key, and sequence/cursor.
- Adapt the selected connector to emit fixtures.

## Acceptance

- Duplicate and out-of-order events are represented.
- Invalid event cannot name an unapproved source.

## Verify

```bash
make test-rag-change-events
```

## Non-goals
