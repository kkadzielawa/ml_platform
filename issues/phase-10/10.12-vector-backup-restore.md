# 10.12 — Back up and restore the vector candidate

## Outcome

Create a version-consistent backup and restore it into a suffixed isolated target.

## Allowed paths

- `scripts/backup/vector_store/**`
- `scripts/restore/vector_store/**`
- `tests/dr/vector_store/**`
- `docs/runbooks/vector-restore.md`

## Deliverables

- Create a version-consistent backup and restore it into a suffixed isolated target.
- Verify counts, index metadata, checksums/sample retrieval, aliases, and ACLs.

## Acceptance

- Original target is untouched.
- Measured RPO/RTO and unsupported guarantees are recorded.

## Verify

```bash
make test-vector-backup-restore
```

## Non-goals

- Destructive in-place restore.
