# 10.04 — Implement incremental indexing

## Outcome

Process bounded change batches, reparse/rechunk/reembed only affected documents, and publish a new logical index version.

## Allowed paths

- `components/index_rag_incremental/**`
- `tests/components/index_rag_incremental/**`

## Deliverables

- Process bounded change batches, reparse/rechunk/reembed only affected documents, and publish a new logical index version.
- Persist cursor only after atomic success.

## Acceptance

- Unchanged documents retain identifiers/embeddings.
- Forced failure replays safely from prior cursor.

## Verify

```bash
make test-rag-incremental-indexer
```

## Non-goals

- Tombstone compaction or distributed queues.
